# 무인도 (AI Simulation Game)

무인도에 떠밀려 온 사람이 **스스로 판단해 살아가는 모습**을 조용히 지켜보는 3D 힐링 시뮬레이션입니다.
사람을 직접 조종할 수는 없지만, 주변 환경에 손길을 보태 그들을 도울 수 있습니다.

- **Next.js 16 (App Router)** + **three.js / React Three Fiber**
- 저장·동시 관찰: **Supabase** (Postgres + Realtime) — 설정하지 않으면 로컬 파일 + 같은 브라우저 탭 간 동기화로 동작
- 배포: **Vercel**

## 플레이

1. 접속하면 입력칸 하나만 보입니다. **시드**를 입력하세요.
2. 처음 쓰는 시드면 새로운 무인도가 시작되고, 이미 있는 시드면 그 섬을 불러옵니다.
3. 창을 닫아도 섬의 시간은 계속 흐릅니다. 다시 접속하면 그동안의 시간을 빠르게 따라잡고 **"당신이 없는 동안"** 일어난 일을 보여 줍니다.
4. 같은 시드로 **최대 3명**이 동시에 같은 섬을 지켜볼 수 있습니다.

| 조작 | 효과 |
| --- | --- |
| 클릭 | **치기** — 나무를 흔들면 열매·가지가 떨어지고, 바위를 치면 돌이 떨어지고, 동물·물고기는 잠시 기절 |
| 드래그 | **옮기기** — 물건·동물·물고기를 집어 옮김. 사람 앞에 놓으면 "선물"로 알아채고 반가워함 |
| 연타 (같은 자리 5번) | **불 지피기** — 장작 위면 더 오래 탐. 비·폭풍·눈에는 잘 안 붙음 |
| 사람 클릭 / 더블클릭 | 상태·감정·성격 보기 / 따라가기 (사람은 건드릴 수 없음) |
| 건물 클릭 | 용도 · 층수 · 내구도 보기 |
| 건물 빠르게 3번 | **두드리기** — 내구도가 40 깎임. 0이 되면 무너지고, 사람이 다치거나 중요한 건물일수록 사기가 크게 꺾임 |
| 맹수 클릭 | 잠깐 휘청거림 (센 놈일수록 금방 정신을 차림) |
| 빈 곳 드래그 · 우클릭(Shift) 드래그 · 휠 | 시점 회전 · 이동 · 확대 (WASD/QE 키도 가능) |

사람이 10명을 넘고 무리가 생기면 왼쪽 목록(모바일은 ☰ → 사람들)은 무리 단위로 묶여 보이고, 무리를 누르면 구성원이 펼쳐집니다.

모바일에서는 탭 = 치기, 한 손가락으로 끌기 = 물건 옮기기(빈 곳이면 시점 회전), **두 손가락으로 끌기 = 시점 이동**, 벌리고 오므리기 = 확대·축소, 사람 두 번 탭 = 따라가기입니다. 오른쪽 위 **☰ 메뉴**에 사람들·연대기·지식·도움말·소리·나가기가 모여 있습니다.

### 앱으로 설치 (PWA)

입장 화면 아래쪽(게임 중에는 오른쪽 위 도구 줄이나 ☰ 메뉴)의 **📥 앱 다운로드**를 누르면 홈 화면·바탕 화면에 앱으로 설치됩니다. 설치한 앱으로 열면 주소창 없이 전체 화면으로 열리고, 한 번 받은 화면과 파일은 기기에 남아 다음부터 빨리 열립니다 (섬 상태는 언제나 서버와 주고받으므로 인터넷은 필요).

- Chrome · Edge · 삼성 인터넷: 버튼을 누르면 브라우저의 설치 창이 뜹니다.
- iPhone · iPad: 버튼을 누르면 **공유 → 홈 화면에 추가** 방법을 알려 줍니다. 맥 Safari는 **파일 → Dock에 추가**입니다.
- 이미 설치했거나 설치한 앱으로 열었으면 버튼이 보이지 않습니다. iPhone·맥 Safari는 브라우저가 설치 여부를 알려 주지 않아서, 안내 창의 **이미 추가했어요**를 누르면 그 브라우저에서 버튼을 감춥니다.
- 설치를 지원하지 않는 브라우저(Firefox 데스크톱 등)에서는 버튼이 나오지 않습니다.

## 시뮬레이션

- **시간**: 게임 하루 = 현실 20분, 한 계절 7일, 1년 28일. 접속이 없어도 서버에 저장된 시각으로부터 경과 시간을 계산해 다음 접속 때 따라잡습니다.
- **날씨**: 맑음 / 흐림 / 비 / 천둥번개 폭풍우 / 눈. 계절별 가중치가 다르지만 **어느 계절이든 맑음이 가장 자주** 나옵니다. 폭풍 때 번개가 나무에 떨어지면 불이 붙기도 합니다.
- **생태계**: 나무·덤불·풀이 짧은 주기로 자라고 번식하며, 열매가 열립니다. 토끼·멧돼지·산양·게·들닭이 번식하고, 바다에는 정어리·고등어(떼)·넙치·도미·오징어·참치(먼바다, 배가 있어야 잡음)가 오가며 가끔 물 위로 뛰어오릅니다. 동식물은 처음 버전보다 약 1.7배 많습니다 (예전 저장본도 불러올 때 채워 넣음).
- **사람 (규칙 기반 Utility AI)**
  - 욕구(배고픔·목마름·기력·체온·교류·즐거움)와 건강, 성격 5요인, **사람마다 다른 감정 민감도**를 가집니다.
  - 매 순간 욕구·감정·성격·마을 상황을 점수로 바꿔 행동을 고릅니다 (채집, 사냥, 낚시, 불 피우기, 요리, 건설, 제작, 농사, 목축, 연구, 대화, 휴식, 노래, 별 보기 …).
  - 감정(기쁨·슬픔·두려움·분노·놀람·애정)에 따라 환호, 춤, 웅크림, 발 구르기, 하트 등 **제스처**를 하고 혼잣말을 합니다.
  - **뗀석기**에서 시작해 불 → 움막 → 창 → 끈 → 돌도끼 → 간석기 → 토기 → 농경 → 통나무집 → 청동 → 문자 → 철기 → 석조 → 천문학 → 과학 → 증기 → 전기까지 33개 기술을 스스로 터득합니다. 생각(연구)과 "해 보면서 배우기"로 진행되며, 관찰자가 불을 보여 주면 불 발견이 빨라집니다.
  - 표류자가 가끔 해변으로 떠밀려 오고, 서로 친해진 두 사람 사이에서 아이가 태어납니다. 굶주림·추위·노환으로 **사망**할 수 있고, 모두가 떠나면 새로운 표류자가 남겨진 흔적(집·도구)을 이어받습니다. 문자를 발명했다면 지식도 전부 이어집니다.
- **질병**: 춥거나 비·눈을 맞으며 밖에 있으면 낮은 확률로 감기에 걸립니다. 1~5단계(3단계 = 독감, 5단계 = 요양소나 마을 밖에서 따로 지내야 함)로 나빠지거나 나아지고, 가까이 붙어 있으면 옮습니다. 약은 섬에서 찾아야 합니다: 약초를 가려내고(약초 감별) → 땅을 파서 약뿌리를 찾고(약 달이기) → 산자락에 숨은 약돌 광맥을 찾아야(약 조제) 연구할 수 있습니다. 아픈 사람은 앓아눕고, 다른 사람이 약을 가져다주며 돌봅니다.
- **자연재해**: 아주 드물게(대략 현실 하루 이틀에 한 번) 지진·태풍·쓰나미가 찾아와 집·밭·창고를 부수고 사람이 다치기도 합니다. 지나가면 사람들이 모여 의논하고 부서진 곳을 함께 고치며, 겪어 본 재해에 맞서는 지식(버팀목 공법 · 기상 관측 · 방파제 · 내진 설계)을 궁리합니다. 큰 지진 뒤에는 쓰나미가 따라오기도 하고, 미리 알아채면 높은 곳으로 피합니다.
- **조직과 문명**: 10명이 넘으면 저마다의 "뜻"(새로움을 좇는지, 함께함을 중히 여기는지)이 맞는 사람끼리 조직을 만들고, 모두의 뜻이 맞으면 문명을 세웁니다. 무리 안에서는 이끄는 사람·농부·어부·사냥꾼·목수·학자·장인·치유사·요리사·뱃사람·지킴이 같은 역할을 맡아 그 일을 먼저, 더 잘 하고 연구와 건설도 빨라집니다. 뜻이 너무 다른 무리끼리는 긴장이 쌓여 다툼이 벌어지고, 끝내 한쪽이 섬의 다른 곳에 따로 터를 잡거나(분열) 화해합니다. 문명 안에서도 뜻이 벌어지면 둘로 갈라질 수 있습니다.
- **땅과 광맥**: 섬은 처음 모습을 그대로 둔 채 넓이가 두 배로 넓어졌습니다 (예전 저장본은 불러올 때 새 땅을 채우고 선착장·방파제 같은 바닷가 시설을 새 해안으로 옮김). 바깥쪽 바위 언덕의 광맥에서 곡괭이로 철·구리·주석, 드물게 은·금·다이아몬드를 캡니다. 실제로 귀한 것일수록 광맥도 적고 캐도 잘 안 나옵니다. 구리+주석은 청동, 철은 무쇠와 무기, 은·금은 장신구(사기를 북돋움), 다이아몬드는 차원문에 쓰입니다.
- **야생 동물**: 사람이 몇 모여 살기 시작하면 아주 가끔 맹수가 나타나 사람을 노립니다. 섬에서 지낸 날이 길수록 늑대 → 곰 → 호랑이 → 검치호로 강해집니다. 맹수를 겪으면 그 시대의 무기(나무 창·활 → 청동검 → 철창 → 화승총 → 소총)와 망루·성루·포대를 궁리하고, 싸울 수 있는 어른은 무기를 들고 맞서며 아이·노인·아픈 사람은 집으로 숨습니다. 여럿이 맞서 크게 다치게 하면 달아나고, 아무도 물지 못하면 제풀에 숲으로 돌아갑니다.
- **건물**: 용도(잠자는 곳 · 맹수 방어 · 도구 제작 · 광석 캐기 …)에 맞는 건물을 처음 지을 때는 누군가 먼저 설계합니다(푸른 도면). 시대가 지날수록 망루·성루·연립주택·아파트·공장처럼 층을 쌓아 더 높게 짓고, 수학과 건축학을 알면 마을을 반듯하게 나눕니다. 모든 건물에는 내구도가 있고 큰 건물일수록 튼튼합니다.
- **사기**: 무너지고 다치고 죽으면 꺾이고, 맹수를 물리치거나 아이가 태어나거나 새 시대에 들어서면 오릅니다. 사기가 높으면 일과 연구가 빨라지고, 낮으면 사람들의 마음도 가라앉습니다.
- **바다와 섬 밖**: 그물·배·항해술로 먼바다 고기잡이를 합니다. 과학 시대에 들어서야만 조선술로 큰 돛배를 지어 바깥 세상에 다녀오고(물자·지식·새 사람을 데려옴), 과학이 아주 많이 발전하면(양자 이론 → 차원문) 차원문으로도 다녀옵니다. 바깥에 남기로 하는 사람도 있습니다.
- **발전 속도(목표치)**: 신석기 ≈ 현실 3~4시간, 청동기 ≈ 반나절, 철기 ≈ 1~2일, 과학 시대 ≈ 4~5일, 전기 ≈ 1~2주, 차원문 ≈ 2주 남짓.

## 구조

```
src/sim/          순수 TypeScript 시뮬레이션 엔진 (React 없음, 결정적 RNG)
  terrain.ts      시드 → 섬 지형 (저장하지 않고 매번 생성)
  world.ts        월드 생성/도우미      weather.ts  날씨
  ecology.ts      식물·동물·물고기      people.ts   욕구·감정·생과 사
  ai.ts           행동 선택과 실행      settlement.ts 연구·건설 계획
  disease.ts      감기와 약             disaster.ts  지진·태풍·쓰나미
  society.ts      조직·문명·역할·다툼   voyage.ts    배와 차원문으로 섬 밖에 다녀오기
  beasts.ts       맹수와 싸움           building.ts  내구도·층수·설계·무너짐
  morale.ts       사기
  interactions.ts 관찰자의 손길         step.ts     한 스텝 진행 / 오프라인 따라잡기
src/game/         브라우저 런타임: 호스트 선출, 동기화(net.ts), 저장, HUD 상태, 사운드
src/components/   3D 장면(game/)과 HUD(hud/), 입장 화면(SeedGate), 앱 설치 버튼(InstallButton)
public/sw.js      서비스 워커 (화면·빌드 파일 캐시, /api 는 건드리지 않음)
src/app/api/world join · save · heartbeat · leave · load
src/server/       저장소 (Supabase 또는 로컬 파일)
```

- **호스트 권한 방식**: 같은 섬을 보는 관찰자 중 가장 먼저 들어온 사람의 브라우저가 시뮬레이션을 돌리고(호스트), 다른 관찰자에게 상태를 방송합니다. 다른 관찰자의 클릭·드래그는 호스트에게 전달됩니다. 호스트가 나가면 다음 사람이 이어받습니다.
- **저장**: 호스트가 15초마다(그리고 창을 숨길 때) 상태를 gzip으로 `/api/world/save`에 보냅니다.
- **인원 제한**: 서버가 하트비트로 관찰자를 세어 4번째 입장을 막고, Realtime Presence로 한 번 더 확인합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

Supabase 환경변수가 없으면 `.data/worlds/`에 저장하고, 같은 브라우저의 탭끼리만 함께 볼 수 있습니다.

```bash
npm run sim:test -- 30          # 헤드리스로 30일 돌려 보기 (연대기·욕구 출력)
npm run sim:era -- 700          # 시대별 도달 시점과 성능 측정
npm run seed -- demo 120 60     # 'demo' 시드로 120일 진행된 섬을 만들고 60분 전에 저장된 것처럼 기록
```

## Supabase 설정

1. Supabase에서 프로젝트를 만듭니다.
2. **SQL Editor**에서 [`supabase/schema.sql`](supabase/schema.sql)을 실행합니다.
3. **Realtime**은 기본 설정 그대로 사용합니다 (Broadcast/Presence, 공개 채널 허용). Realtime 설정에서 *Private channels only* 를 켜지 않았는지 확인하세요.
4. **Project Settings → API**에서 아래 값을 Vercel 환경변수로 넣습니다.

| 변수 | 값 |
| --- | --- |
| `SUPABASE_URL` | Project URL |
| `SUPABASE_ANON_KEY` | anon (또는 publishable) 키 — 브라우저 Realtime용 |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role (또는 secret) 키 — 서버 전용, 절대 공개 금지 |
| `ISLAND_KEY_SALT` | (선택) 시드 해시용 소금값. 한 번 정하면 바꾸지 마세요 |

Vercel의 Supabase 연동을 쓰면 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`가 자동으로 들어오는데, 이 이름들도 그대로 인식합니다.
